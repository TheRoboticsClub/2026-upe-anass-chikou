Esta semana hemos cerrado la grabación de la ejecución, que ya está funcional en despliegue. Además, hemos empezado tres tareas nuevas: grabar videotutoriales de Unibotics, revisar los evaluadores automáticos de los ejercicios y, más adelante, hacer responsive las páginas web de Unibotics.

## 1. Videotutoriales de Unibotics
Hemos empezado a grabar y editar los videotutoriales. El primero explica cómo entrar a un ejercicio desde la página principal, y el siguiente mostrará cómo usar la grabación de la ejecución.

## 2. Evaluadores automáticos
La idea es añadir un evaluador automático a algún ejercicio más de Robotics Academy. Para ello, primero hemos revisado los que ya existen (FollowLine, ObstacleAvoidance, BasicVacuumCleaner y LocalizedVacuumCleaner) para entender cómo funcionan y cómo se guardan en la base de datos de eventos de Unibotics. El evaluador se ejecuta en el propio frontend del ejercicio, dentro de su `WebGUI.tsx`, mientras se ejecuta el código del alumno.

---

## Planes para la Siguiente Semana
- Terminar los videotutoriales de Unibotics.
- Guardar en la base de datos de eventos la nota de los evaluadores automáticos. El alumno ejecuta el ejercicio como siempre, al terminar se le muestra la nota y, con un botón, puede guardarla.
- Añadir un evaluador automático a otro ejercicio.
- Empezar a hacer responsive las páginas web de Unibotics.
