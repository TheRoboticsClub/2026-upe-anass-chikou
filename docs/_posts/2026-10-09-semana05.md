Esta semana hemos continuado con la integración del sistema de captura y procesamiento de audio. He preparado y ejecutado el entorno de `RoboticsAcademy` mediante Docker y he empezado a estudiar cómo funciona internamente el proyecto para poder integrar mi aplicación creando un nuevo ejercicio.


## 1. Estudio del funcionamiento interno de RoboticsAcademy
Al inicio de la semana, he estado estudiando cómo funciona internamente `RoboticsAcademy` para poder integrar mi aplicación dentro del proyecto. Me he enfocado en lo básico para poder entender cómo se conecta el frontend con la aplicación que corre en el contenedor, además de comprender cómo se renderizan todos los componentes y cómo manejar algunos estados del manager.

También he estado mirando cómo se cargan y muestran las diferentes herramientas (`tools`) de cada ejercicio. Al principio no entendía cómo la cámara aparecía dentro de un ejercicio, especialmente porque hay otros ejercicios en los que no se puede activar o desactivar mediante un `toggle`. Investigando el funcionamiento interno, he podido entender que al iniciar el proyecto se cargan los datos correspondientes del ejercicio y dentro de ellos se encuentran las `tools` definidas para cada ejercicio. Posteriormente, estas herramientas se obtienen y se muestran en la interfaz para poder utilizarlas.

Finalmente, he estado estudiando cómo se muestra el `WebGUI.tsx` dentro de cada ejercicio y cómo se importa desde la carpeta correspondiente del proyecto. Además de utilizar como referencia el ejercicio `Basic Computer Vision` para entender cómo está organizado un ejercicio, y como modelo para poder crear mi propio ejercicio.

## 2. Preparación y ejecución con Docker
He preparado el repositorio y su entorno de ejecución mediante Docker siguiendo la [guía](https://github.com/JdeRobot/RoboticsAcademy/blob/humble-devel/docs/InstructionsForDevelopers.md) para levantar el proyecto.

He configurado el entorno de desarrollo utilizando `Docker Compose` y he comprobado el funcionamiento de los diferentes contenedores necesarios para ejecutar RoboticsAcademy. 

## 3. Creación del nuevo ejercicio Audio-In
La idea es crear un nuevo ejercicio y seguir la estructura que utilizan los ejercicios existentes, tomando `Basic Computer Vision` como referencia.

Una de las ideas que tenía al principio era crear un componente `Microphone.tsx` dentro del frontend, de forma que pueda contener la lógica relacionada con el micrófono y pueda reutilizarse posteriormente en diferentes ejercicios. Aunque por ahora nos limitaremos a probar solo el funcionamiento básico de la aplicación.
